# CAML 界面设计

更新日期：2026-11-09

## 1. 设计意图

主任务是选择游戏实例并启动游戏。界面把“启动设置”放在主区域，
把“运行日志”放在支持面板；顶栏只保留应用身份和主导航，主题选择位于外观设置。

## 2. 布局与自适应

- 顶栏：`CAML` 标题、副标题、主导航“主页 / 下载 / 设置”。
- 主页：当前启动设置和运行日志工作区。
- 主页实例信息使用圆角分组，按三行显示“当前实例 / 游戏位置 / 存档位置”，并放大字号。
- “浏览游戏实例”和“管理实例”等宽，各占启动按钮宽度的一半左右。
- 下载页：左侧“正式版 / 快照版 / 远古版”胶囊。内容页从官方清单分别读取正式版、
  快照版和远古版（Alpha/Beta），各自按发布时间从新到旧列出；版本号左对齐，最后更新时间右对齐。
  点击版本进入下载设置页，顶部是取消、实例名字标签和输入框，输入框默认官方版本号。
  页面主体由六条组成：版本信息、选择 Forge 版本、选择 OptiFine 版本、选择 Fabric 版本、
  选择 Fabric API 版本、选择 NeoForge 版本；取消位于左上角，底部整宽“下载实例”按钮安装原版或所选加载器。
  Fabric Loader 从 Fabric Meta 获取，Fabric API 从 Modrinth 获取；Forge/NeoForge 镜像源优先读取 BMCLAPI JSON，
  官方源读取各自 Maven 元数据。五类加载器请求并发执行，先返回的选项先显示。
  Forge、Fabric、NeoForge 互斥；OptiFine 只与 Forge 兼容，选择 Fabric 或 NeoForge 时会清空并禁用 OptiFine。
  未选择加载器时安装原版。
- 实例名输入停止约 0.5 秒后自动调用后端检查格式、重复目录和加载器同名校验，
  结果显示在输入框下方；检查通过前“下载实例”保持禁用。
- 点击“下载实例”后进入独立下载进度页：左侧卡片显示实时网速和累计下载量，
  右侧卡片显示总进度、当前文件、当前阶段和按顺序增长的阶段列表。
  返回下载列表后下载继续，完成或失败状态仍写入启动器日志。
- 模组子页与版本列表共用左侧导航：侧边栏宽度取窗口宽度的 `1/6`，并限制在 `180–260`
  设计像素（实际宽度再乘以 UI 缩放因子）。比例按逻辑像素计算，因此 150% 缩放的 1080p 屏幕
  （逻辑宽度约 `1280`）会落在按因子缩小后的上限，而不是假设存在 `1920×1080` 的逻辑空间。
- 模组子页尺寸全部集中在 `ModDownloadLayout`；断点按内容区宽度（已扣除左侧导航）判断，
  内容区左右留白 `40`、上下 `32`，搜索卡与详情卡内边距 `24`、内部间距 `18`，
  标题“搜索 Mod”位于卡片左上。
- 搜索表单三种方向：内容宽度 `>= 660` 为两行两列、“标签在左”，名称/游戏版本输入框与
  来源/加载器下拉框按 `2:1` 分配列宽；`520–659` 为“标签在上”的两行两列；`< 520` 为单列纵向堆叠。
  切换方向只改变摆放方式，控件尺寸、行高和字号保持不变。
- 搜索结果行最小高 `112`、图标 `88`，左侧贴边 `4px` 橙黄强调条，名称与来源标签分居行首行尾，
  摘要和加载器/版本信息各占一行并以省略号截断。
- 结果行用“下层透明按钮 + 上层只读正文”的叠层结构：按钮只负责点击、悬停和焦点，
  行高由图标 `88` 与上下内边距 `12` 共同决定（`12 + 88 + 12 = 112`）。
  不使用按钮自身的 `graphic` 承载正文——`caml.css` 的 `-fx-min-height: 44` 会覆盖代码设置，
  叠加 `Region.USE_PREF_SIZE` 后皮肤首选高度会塌陷为 `0`，导致图标与文字溢出并压到相邻行。
- 搜索卡、状态、结果列表和分页整体放在页面滚动容器中：高度不足时由整页纵向滚动接管，
  结果行保持 `112` 最小高度而不被裁切，分页随列表滚动到内容末尾。
- 设置页：左侧“游戏设置 / 下载设置 / 外观”侧边栏，右侧对应内容，不显示页面标题。
- 设置页右侧内容支持纵向滚动，内容较长时可以从上向下滚动查看。
- 游戏设置：“游戏位置”圆角分组包含路径输入、浏览和保存；“版本隔离”组包含“完全版本隔离”和“不进行版本隔离”两个圆形单选项；“Java”组包含“自动选择 / 手动选择”两个圆形单选项、重新扫描按钮、添加 Java 按钮、Java 地址下拉框和选中 Java 的版本信息；“内存”组包含描述、内存摘要和叠层滑块。
- Java 自动选择时下拉框禁用并呈灰色；手动选择时下拉框可用，列出整机扫描结果和手动添加的 Java，按真实路径去重合并，框内只显示 Java 可执行文件地址。
- 三个分组按内容区宽度拉齐；“已使用 / 游戏 / 可用 / 总内存”保持单行，灰色辅助文字统一放大。
- 主页“浏览游戏实例”进入二级列表，列出当前游戏位置扫描出的全部实例；
  进入和返回都通过 `CamlPageHost` 播放与顶级页面一致的淡入/位移动画。
  实例条目使用淡灰底，悬停时变为淡黄色，保留橙黄描边；返回按钮使用同样的底色和悬停状态。
- “管理实例”进入独立二级页，当前只显示返回和标题，内容为空。
- 外观：使用圆角组承载主题选择。
- 外观设置包含“语言”分组：自动/手动单选项和语言下拉框。自动模式的默认语言是 `en_us`，
  只在简体中文系统上使用 `zh_cn`（繁体中文待做，暂回退 `en_us`）。手动模式使用下拉框选择的
  `zh_cn` / `en_us` / `fn_cn`，切换后立即刷新界面文案。
- 外观设置包含“语言回退”分组：系统语言、默认语言、显示裸键、自定义语言四个单选按钮；只有自定义
  模式启用语言下拉框。系统语言和自定义模式不追加英语兜底，缺失内容直接显示裸键。修改后由后端
  重新生成语言快照并刷新当前界面。
- 下载设置：上方“下载源”圆角组，包含“尽可能使用镜像源 / 尽可能使用官方源 / 导入自定义 API”
  三个圆角单选项；只有选择自定义时输入框可用，切换到其他源时输入框禁用但保留网址。
  下载页的版本列表加载提示会同步显示当前下载源；下载源保存成功后，已加载的分类列表和
  当前加载器设置页的 Fabric/Forge/NeoForge/OptiFine 版本列表都会失效并重新请求。
  下方“设定下载并发数”圆角组使用 1–256 的整数滑块和并发数文字；字号与游戏设置一致。
- 两个侧边栏都不使用灰色背景，只用一条右侧分隔线，并从顶栏底部铺到页脚。
- 主工作区：左侧启动设置，右侧运行日志。
- 窗口初始尺寸按主屏幕可用区域计算：约为宽 `68%`、高 `74%`，并限制在 `990x618` 与
  `1980x1237` 之间——这两个值分别是设计基准 `1440x900` 缩小到最小缩放因子、放大到最大缩放因子的结果。
- 小屏幕（如 1366x768）自动收缩最小尺寸，窗口不超过桌面可用区域，初始位置居中。
- **整体缩放**：设计基准是 `1440x900` 的逻辑窗口与 `16px` 根字号。窗口尺寸变化时，
  `UiScale` 按 `min(宽/1440, 高/900)` 计算缩放因子并量化到 `1/16`（根字号取整数像素），
  钳制在 `0.6875–1.375`（根字号 `11–22px`）。`MainView` 把因子换算成根字号写进根节点，
  CSS 中除 `1px` 描边外的所有长度都用 `em`，因此字号、控件尺寸、圆角、内边距与留白
  随窗口同比例放大或缩小：大屏与小屏看到的界面比例与图示一致。
- 需要按比例计算、无法用 CSS 表达的几何（模组页、工作区分栏、侧边栏宽度）由代码读取
  同一个 `UiScale` 因子换算，与 CSS 结果一致；同一属性不会在代码与样式表中同时赋值。
- 窗口可自由缩放；缩放时字号与控件一起等比变化，并在宽度跨过断点时切换布局方向，
  不出现横向滚动条（字段区已关闭横向滚动，日志文本框保留自身的内部滚动条）。
- 窗口宽度 `>= 900`（乘以缩放因子）：左右分栏，日志作为持续可见的支持面板，分隔条位于 `0.56`。
- 窗口宽度 `< 900`（乘以缩放因子）：上下堆叠，表单在上、日志在下，分隔条位于 `0.62`，并放宽最小高度：
  表单 `320 → 240`、日志面板 `220 → 140`、日志文本区 `200 → 120`（首选高度 `460 → 260`，均为设计像素）。

## 4. 主题角色

- 页面背景：`-caml-background`
- 启动设置区：`-caml-surface`
- 支持面板：`-caml-surface-container`
- 日志输入表面：`-caml-surface-lowest`
- 主操作：`-caml-accent` + `-caml-on-accent`
- 次要文字：`-caml-on-surface-muted`
- 边框和分隔线：`-caml-border-subtle`
- 错误：`-caml-danger`

默认主题 mango 为白底、灰色支持面板、黄色强调色和深色文字。

## 5. 状态与反馈

- 默认：不显示状态文字；启动中、成功或失败时才显示状态标签。
- 启动中：按钮变为“启动中...”并禁用。
- 失败：状态文字切换为错误文案和错误色，日志保留诊断信息。
- 游戏日志会过滤 Log4j XML，显示为 `[HH:mm:ss] [线程/级别]: 消息`，堆栈保留后续行。
- 主题切换：立即应用，选择写入 `~/.caml/theme.txt`。
- 主导航：同一时间只保留一个选中项，主页状态在切换页面时保留。
- 内存滑块：同一条轨道上下叠层。底层灰色条宽度为 `系统已使用 + 游戏分配`，
  上层黄色分配线和 `18px` 空心球覆盖左侧；灰色可见部分位于小球右侧并随球移动，
  剩余未使用部分为半粗淡灰色。小球按下缩至 `0.84` 倍，整条滑块不绘制聚焦边框。
- 系统内存每 500ms 重新读取一次，读取后立即刷新数值和灰色条，不等待页面重开。
- 游戏位置输入是草稿；只有点击“保存”并通过目录校验后，才更新共享状态和后端配置。
- 版本隔离选择立即写入共享状态和 `~/.caml/settings.properties`，下一次启动使用所选模式；
  主页“存档位置”随选择立即切换。
- 下载源选择立即写入设置；自定义 API 地址会缓存到设置文件，切回镜像/官方源后仍保留在输入框中。
- 加载器下拉框切换时，被清空的 Forge/Fabric/NeoForge 选项会恢复
  `请选择 ... 版本` 提示文字，不会留下空白选项框。
- 启动成功后把实例 ID 写入 `~/.caml/settings.properties` 的 `lastInstanceId`；
  下次启动优先恢复该实例，实例不存在时才回退到目录扫描结果。
- 最大内存保存到 `~/.caml/settings.properties`，滑块停止变化约 300ms 后持久化。
- 设置侧边栏：同一时间只保留一个选中项，游戏设置默认选中。
- 设置子项选中：不透明橙黄胶囊，白色文字。
- 设置子项未选中：透明填充，橙黄实线边框，橙黄文字。
- 空日志：保留空白日志表面，不额外制造空状态插画。
- 所有界面文案来自 `lang/*.json`：视图和控制器通过 `UiText` 显示后端语言服务提供的最终文本，
  不写死按钮、标签、提示和状态文字，也不执行回退或格式化。
- 语言文件由独立 `CAMLLanguage` 模块的 `generator.lang` 包生成（`LanguageTranslationGenerator` 子类）
  以 `t.put(key, value)` 登记生成，执行 `:CAMLLanguage:generateTranslation` 刷新；
  每次启动与内置资源比对，不一致就按内置文件重写；非内置语言文件原样保留，之后从该目录加载。

## 6. 无障碍

- 所有表单控件都有持久标签，并通过 `Label.setLabelFor` 关联。
- 按钮最小高度 `44px`、输入控件最小高度 `40px`（设计像素，`caml.css` 中用 `em` 表达，
  随根字号等比缩放，不会在小屏上缩到无法点击）。
- 按钮、输入框、下拉框、微调框和日志框都有可见焦点样式。
- 状态不只依赖颜色，同时提供文字说明。
- 主题切换是即时设置，不需要冗余保存按钮。
- 尚未完成真实屏幕阅读器、系统文字缩放和 200% DPI 的端到端验证。

## 7. 动效

动效参考 PCL 的 `MyPageRight` 页面进入/退出动画和 `MyButton` 按压缩放，
但缩短到适合桌面启动器的长度：

- 顶部导航使用胶囊圆角按钮。
- 顶部栏整体不做上下淡出，避免 CAML 标题和导航闪烁；只保留导航按钮自身反馈。
- 顶部导航和设置侧边栏按钮按下均缩放至 `0.96`，约 `70ms`；松开约 `160ms` 恢复。
- 旧页面约 `90ms` 淡出并上移 `4px`。
- 新页面延迟约 `30ms` 后，在 `220ms` 内从上方 `12px` 淡入归位。
- 带侧边栏的页面切换时，侧边栏额外向左淡出/从左侧淡入，并通过反向 Y 位移抵消页面上下移动。
- 设置页切换子项时，右侧内容先约 `80ms` 淡出，再约 `180ms` 淡入，不改变侧边栏位置。
- 连续快速切换时停止上一次动画并回到稳定状态，避免页面叠影。
- 设置 `-Dcaml.reduceMotion=true` 时跳过页面、侧边栏和按钮动画。

主题和状态变化立即生效，不添加装饰性动画。

## 8. 自审计

| 类别 | 分数 | 说明 |
|---|---:|---|
| 任务清晰度 | 2 | 启动设置和主按钮位置明确 |
| 信息层级 | 2 | 主区域、支持面板和底栏层级清楚 |
| 组件语义 | 2 | 下拉、输入、滑块、日志和主操作匹配用途 |
| 令牌纪律 | 2 | 颜色全部使用 `-caml-*` 主题令牌 |
| 自适应行为 | 2 | 根字号随窗口等比缩放，断点随缩放因子移动，大屏小屏比例一致 |
| 状态与反馈 | 1 | 有启动状态和错误文字，但尚无错误对话框和完整恢复路径 |
| 无障碍 | 1 | 标签、焦点和目标尺寸已处理，尚未做屏幕阅读器与文字缩放实测 |
| 表现克制 | 2 | 只保留一个黄色主操作，没有多余卡片和装饰徽章 |

存在 `1` 分的项目不属于阻塞性失败，但仍是后续改进项。
