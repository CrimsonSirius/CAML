# CAML 界面设计

更新日期：2026-11-05

## 1. 设计意图

主任务是选择游戏位置和版本并启动游戏。界面把“启动设置”放在主区域，
把“运行日志”放在支持面板；顶栏只保留应用身份和主题选择。

## 2. 布局与自适应

- 顶栏：`CAML` 标题、副标题、主题选择器。
- 主工作区：左侧启动设置，右侧运行日志。
- 窗口宽度 `>= 900`：左右分栏，日志作为持续可见的支持面板。
- 窗口宽度 `< 900`：上下堆叠，表单在上、日志在下。
- 表单使用“标签在上、控件在下”的纵向结构，避免窄窗口下标签被挤压。
- 启动按钮固定在表单底部；字段区域独立滚动，主操作始终可见。
- 底栏显示后端状态和数据目录。

## 3. 组件映射

| 用途 | 组件 |
|---|---|
| 游戏位置 | `CamlComboBox` + outlined `CamlButton` |
| 游戏版本 | 可编辑 `CamlComboBox` |
| 离线用户名 | `CamlTextField` |
| 最大内存 | `CamlSpinner` |
| 启动游戏 | filled `CamlButton` |
| 运行日志 | `CamlTextArea` |
| 主题选择 | `CamlComboBox<ThemeInfo>` |
| 分区标题 | `caml-headline-small` / `caml-title-large` |

## 4. 主题角色

- 页面背景：`-caml-background`
- 启动设置区：`-caml-surface`
- 支持面板：`-caml-surface-container`
- 日志输入表面：`-caml-surface-lowest`
- 主操作：`-caml-accent` + `-caml-on-accent`
- 次要文字：`-caml-on-surface-muted`
- 边框和分隔线：`-caml-border-subtle`
- 错误：`-caml-danger`

默认主题为白底、灰色支持面板、黄色强调色和深色文字。

## 5. 状态与反馈

- 默认：显示“准备就绪”。
- 启动中：按钮变为“启动中...”并禁用。
- 失败：状态文字切换为错误文案和错误色，日志保留诊断信息。
- 主题切换：立即应用，选择写入 `~/.caml/theme.txt`。
- 空日志：保留空白日志表面，不额外制造空状态插画。

## 6. 无障碍

- 所有表单控件都有持久标签，并通过 `Label.setLabelFor` 关联。
- 按钮最小高度 44px，输入控件最小高度 40px。
- 按钮、输入框、下拉框、微调框和日志框都有可见焦点样式。
- 状态不只依赖颜色，同时提供文字说明。
- 主题切换是即时设置，不需要冗余保存按钮。
- 尚未完成真实屏幕阅读器、系统文字缩放和 200% DPI 的端到端验证。

## 7. 动效

当前不添加装饰性动效。主题和状态变化立即生效，避免在启动器这种工具界面中
引入无意义的动画。

## 8. 自审计

| 类别 | 分数 | 说明 |
|---|---:|---|
| 任务清晰度 | 2 | 启动设置和主按钮位置明确 |
| 信息层级 | 2 | 主区域、支持面板和底栏层级清楚 |
| 组件语义 | 2 | 下拉、输入、数字、日志和主操作匹配用途 |
| 令牌纪律 | 2 | 颜色全部使用 `-caml-*` 主题令牌 |
| 自适应行为 | 2 | 900px 断点切换左右/上下布局 |
| 状态与反馈 | 1 | 有启动状态和错误文字，但尚无错误对话框和完整恢复路径 |
| 无障碍 | 1 | 标签、焦点和目标尺寸已处理，尚未做屏幕阅读器与文字缩放实测 |
| 表现克制 | 2 | 只保留一个黄色主操作，没有多余卡片和装饰徽章 |

存在 `1` 分的项目不属于阻塞性失败，但仍是后续改进项。
